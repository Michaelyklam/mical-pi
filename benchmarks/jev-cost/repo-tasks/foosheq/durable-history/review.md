# Durable history sessions

## Context

The committed editor already separates eight hardware slots from visible editor membership. Its reducer supports grouped transactions and an 80-step undo history, but workspace persistence saves only one profile. This task requests a separate durable session format and explicit cancellation. It does not claim that the existing behavior is a production defect.

Split: `calibration`. Estimated difficulty: moderate. Kind: `feature`.
These are author estimates, not measured model outcomes. This task is independent of the other three tasks; its baseline contains none of their solutions.

## Why this needs repository work

The implementation must distinguish an in-flight preview from committed state, preserve a redo branch after rollback, and keep legacy imports tolerant while making session restoration strict. Reusing the EQ serializer alone loses editor membership. Serializing present during a drag records an uncommitted preview. Storage recovery must be read-only and must not overwrite presets or the old workspace.

The baseline contains 6 unmodified committed source/test/fixture files (2,758 lines, 84,915 bytes), plus an authored minimal ESM package and test configuration. It retains the complete selected modules and their existing tests, not extracted toy functions. The task is limited to model modules; UI wiring and visual behavior are explicitly outside scope.

Reference replacement paths:

- `src/lib/editorDocument.ts`
- `src/lib/workspace.ts`
- `src/lib/workspaceSession.ts`
