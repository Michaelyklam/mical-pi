# Grouped graph gestures with conflict-aware commit

## Context

The committed graph helper captures field patches and handles single-band keyboard nudges. EditorDocument owns slot visibility and workspace owns undo/redo. This feature adds multi-selection gestures that remain outside history until a single rebased commit. It is a model-level graph feature, not a replacement DSP puzzle or a UI screenshot task.

Split: `evaluation`. Estimated difficulty: hard. Kind: `feature`.
These are author estimates, not measured model outcomes. This task is independent of the other three tasks; its baseline contains none of their solutions.

## Why this needs repository work

Group limits must be computed before rounding, across linear gain and logarithmic frequency/Q axes. Updates are absolute from pointerdown state, so incremental accumulation is wrong. Commit must reconcile fields against a concurrently edited document by slot ID, preserving new slots, bypass and metadata while reporting conflicts. Undo must restore the latest pre-commit document rather than the stale gesture base.

The baseline contains 8 unmodified committed source/test/fixture files (2,931 lines, 90,414 bytes), plus an authored minimal ESM package and test configuration. It retains the complete selected modules and their existing tests, not extracted toy functions. The task is limited to model modules; UI wiring and visual behavior are explicitly outside scope.

- `src/components/graphBandDraft.ts`
- `src/lib/workspace.ts`

## Hidden coverage

- Sorted visible selection, visible bypassed slots, detached snapshots and frozen-input immutability.
- Upper/lower group bounds, absolute updates, unchanged-axis precision, empty selections, non-finite rejection and very large finite deltas.
- Reordered slot arrays, concurrent metadata/Q/bypass/addition changes, partial field conflicts, deterministic conflict order, removal and profile replacement.
- Identity-preserving no-ops, one-step commit, undo/redo membership, serialization, nested-transaction rejection and the existing 80-step cap.
