# Controlled writing

Use precision over personality.

- Use one term for each concept.
- Put one action in each procedural step.
- State conditions before the action they govern.
- Name the actor when responsibility matters.
- Use direct verbs instead of vague phrasal verbs.
- Split sentences that contain separate requirements.
- Avoid figurative, promotional, or conversational language.
- State the expected result and how to verify it.
- Preserve every prerequisite, warning, exception, and failure condition.
